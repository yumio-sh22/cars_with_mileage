## Анализ рынка автомобилей

Проект по анализу рынка подержанных автомобилей с использованием методов Data Science и машинного обучения для предсказания цен.

## О проекте

Этот проект представляет собой комплексный анализ данных о продаже автомобилей с Avito, включая:
- **Сбор и очистку данных**
- **Разведочный анализ (EDA)**
- **Визуализацию**
- **Построение ML-модели** для предсказания цен

## Результаты

### Основная статистика
- **Проанализировано:** 50 автомобилей
- **Средняя цена:** 852,520 руб
- **Уникальных марок:** 21
- **Топ-5 марок:** Lada, Hyundai, Ford, Kia, Opel
- **Годы выпуска:** 1998-2024

### ML Модель
- **Алгоритм:** RandomForestRegressor
- **Точность (R²):** 0.811 (81.1%)
- **Средняя ошибка (MAE):** 256,746 руб
- **Важные признаки:** марка, год выпуска, пробег

## Ключевые находки

### 1. Факторы цены
- **Марка автомобиля** - самый важный фактор
- **Год выпуска** - значительное влияние
- **Пробег** - умеренное влияние

### 2. Визуализации
- Зависимость цены от года выпуска
- Распределение цен по брендам
- Боксплоты цен за последние 10 лет

### 3. Инсайты
- Автомобили премиум-брендов сохраняют ценность лучше
- Новые автомобили имеют более высокую стоимость
- Определенные бренды демонстрируют лучшую сохранность цены
